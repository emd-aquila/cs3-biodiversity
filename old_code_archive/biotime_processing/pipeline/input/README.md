# Inputs

This folder intentionally contains only small trial fixtures.

- `predicts_abundance_study_start_2000_top_10.csv`: first 10 rows of the slim
  abundance-based PREDICTS table after applying the study-start filter.

Large canonical BioTIME and PREDICTS files are reused from
`../../novel_testing/data/` and `../../old/build_predicts/tmp/`. Their resolved
paths are configured in `../code/01_config.R`.
